About this project

PropertyHub Ireland is the sample web application for my CI/CD pipeline assignment. Every change goes through an automated pipeline: build, test, code analysis, security scanning, containerisation, deployment to Kubernetes on AWS, and monitoring.

Pipeline stages (Jenkinsfile)

  1. Build & test: Maven, JUnit unit + integration tests, JaCoCo 70% coverage gate
  2. Code quality: SpotBugs + FindSecBugs, SonarQube quality gate
  3. Security: Trivy (dependencies), Gitleaks (secrets), Hadolint, Checkov, cfn-lint
  4. Docker build: multi-stage, distroless, non-root image
  5. Image scan: Trivy, plus a CycloneDX SBOM
  6. Container smoke test
  7. Push image to Docker Hub (main branch)
  8. Deploy to k3s on AWS via SSM, with helm --atomic rollback and a Prometheus gate
  9. Verify production: smoke test checks the new commit is live

Technology

  • Java 21, Spring Boot 3.5, Thymeleaf, Micrometer
  • Docker, Docker Compose, Kubernetes (k3s), Helm
  • Jenkins (configured as code), SonarQube
  • AWS EC2, CloudFormation, Secrets Manager, SSM
  • Prometheus, Grafana, Alertmanager, Loki

What the app does

  • Search homes to buy or rent across Ireland
  • Instant valuation and a deal score for every listing
  • Rental yield and buy-to-let cash flow
  • Affordability under the Central Bank of Ireland mortgage rules
  • County market insights and a REST API
